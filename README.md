# mojos-render

Blender 5.2.2 (official blender.org Linux build, sha256 checked) on RunPod's Ubuntu 24.04 image, plus a 15-line loop
(`render_all.py`) that renders every `.blend` in a folder to PNG on the GPU. Used as a RunPod pod template.

Image: `ghcr.io/jomspangilinan/mojos-render:5.2.2`. Holds no project files; scenes are sent at render time.
